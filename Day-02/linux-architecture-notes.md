Linux Architecture:
1. Hardware
Physical parts of computer
Examples:
CPU
RAM
Hard Disk
Keyboard
Network Card

2. Kernel
Core part of Linux Operating System
Works as bridge between hardware and software
Manages:
Memory
CPU
Devices
Processes

3. Shell
Interface between user and kernel
Takes user commands and sends them to kernel
Example:
Bash
Zsh

4. Applications
Programs used by users
Examples:
Chrome
VS Code
Nginx
Docker

5. systemd / Init
First process started during boot (PID 1)
Starts and manages services in Linux
Handles:
Boot process
Service restart
Background services
Logs
