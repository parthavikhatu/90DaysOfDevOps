OSI Model
| Layer | Name         | Purpose                                  |
| ----- | ------------ | ---------------------------------------- |
| L7    | Application  | User-facing protocols (HTTP, DNS, SMTP)  |
| L6    | Presentation | Data formatting, encryption, compression |
| L5    | Session      | Manages communication sessions           |
| L4    | Transport    | End-to-end communication (TCP, UDP)      |
| L3    | Network      | Routing and IP addressing (IP)           |
| L2    | Data Link    | MAC addresses, switching, Ethernet       |
| L1    | Physical     | Cables, signals, network hardware        |

TCP/IP Stack
| TCP/IP Layer | OSI Equivalent | Examples              |
| ------------ | -------------- | --------------------- |
| Application  | L5–L7          | HTTP, HTTPS, DNS, SSH |
| Transport    | L4             | TCP, UDP              |
| Internet     | L3             | IP, ICMP              |
| Link         | L1–L2          | Ethernet, Wi-Fi       |
